BIGHEART ENCHANTED BIRTHDAY WEBSITE
===================================

WHAT IS INCLUDED
- index.html              Main website
- styles.css              Complete design and responsive animations
- script.js               All interactions and effects
- birthday-standalone.html Entire website in one convenient HTML file

HOW TO OPEN
1. Open the folder.
2. Double-click index.html.
3. The website runs locally in any modern browser.

FASTEST OPTION
Double-click birthday-standalone.html. It contains the complete site in one file.

HOW TO PUBLISH
Upload index.html, styles.css, and script.js to the same folder on GitHub Pages,
Cloudflare Pages, Netlify, or any basic web host.

PERSONALIZATION
The birthday name is already set to BigHeart.
Edit the CONFIG object at the top of script.js to change messages, wishes, jokes,
and truth-scanner results.

NO DEPENDENCIES
This website does not require frameworks, libraries, package managers, or a server.
